# 3年生 非公式　講義・実習ダッシュボード

医学類3年春学期の複雑な講義・実習日程を効率的に管理するためのツールです。

## 📅 主な機能
- **LMS　/ 出席状況確認**: LMSや出席状況確認のページへ容易にアクセスできます。
- **重要予定カレンダー**: 課題の締切、定期試験、学外実習など「落とせない予定」を可視化。

## ⚠️ 注意事項
- カレンダーは個人が作成したものです。
- **最新かつ正確な情報は、必ず原本PDF、または大学からの連絡を確認してください。**
